Under the hood

What's actually running live here, and what a full build needs.

Live in this demo

The conversation itself

The chat above is a real, running language model, prompted per-persona to reply in warm, natural Tanglish — the way a father, mother, or grandparent would actually text. Nothing here is pre-scripted.

Needs a backend

Photo → 3D avatar

Turning one photo into a rigged, expressive 3D face (for mobile, likely a Ready Player Me / MetaHuman-style pipeline) needs server-side reconstruction and a game engine or WebGL rig — beyond what a single web page can do, but a well-scoped mobile build.

Needs consent + backend

Cloning their actual voice

Real voice cloning (ElevenLabs or similar) needs a clean voice sample, server-side API calls, and — importantly — the person's own consent if they're living. The voice button here uses your browser's built-in text-to-speech as a stand-in, clearly not the real thing.
